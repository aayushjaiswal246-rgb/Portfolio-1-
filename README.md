## Deployment to GitHub Pages

1. Build static output:
   ```bash
   npm run build
   ```
2. The compiled assets will be written to `dist/` with relative paths (`./assets/...`).
3. Deploy the contents of `dist/` to the `gh-pages` branch or the root of your GitHub Pages repository (`aayushjaiswal246-rgb.github.io`).
